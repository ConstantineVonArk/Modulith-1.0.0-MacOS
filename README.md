# Modulith 1.0.0 — Pixel Architecture Studio

Modular architectural modelling and isometric pixel-art facade editor for macOS.

## Launch

Double-click **Modulith.app** or use **START_MAC.command** as a fallback. The app requires Python 3.10–3.13 with Tkinter. Pillow and optional NumPy are installed on first launch if necessary.

## Files and compatibility

The app contains the same renderer and sprite libraries as SC3K Architecture Builder 3.48.23. Existing SC3K facade and building JSON projects are supported. Volume JSON exports retain legacy Russian roof-type and roof-accessory values for compatibility with previous SC3K versions.

Startup log: `~/Library/Logs/Modulith/startup.log`.

Modulith is a working product name; this package does not establish trademark clearance.
